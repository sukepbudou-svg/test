# boatrace-predictor / PERRY AI プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、
ローカルWeb（Flask + SQLite）に自動記録する。
ツール名: **PERRY AI**（黒船のペリーをコンセプトにしたAI予想キャラクター）

## 現在の予想設定（2026-08-25 荒れPTスコア方式・再設計版）

### ラベル・参戦判定（src/model/predictor.py: _calc_race_pt）
「配当サイズに直結する要素」を重く、「荒れる確率だけの要素」を軽く配点した加算式PTに刷新。
参戦ラインは `PT_MIN_SCORE`（現在13点・暫定値）以上。

| ラベル | 条件 | 参戦 | 色 |
|--------|------|------|----|
| **神熱** | PT合計 ≥ PT_MIN_SCORE | ○ | ゴールド（#ffcc00）|
| **見送り** | PT合計 < PT_MIN_SCORE | ✗ | グレー |

**A. 市場のミスプライシング（最大4点・配当サイズに直結・ライブオッズ取得時のみ）**
| 条件 | 点数 |
|------|------|
| 1号艇ライブ最安オッズ 4〜6倍（一番おいしいゾーン） | +4 |
| 7〜10倍 | +3 |
| 11〜15倍 | +1 |
| 3倍以下 or 16倍以上 | 0 |

**B. 外艇の脅威の複数性（最大11点・配当サイズに直結）**
| 条件 | 点数 |
|------|------|
| 前付け（4〜6号が1〜2コース進入） | +3 |
| 外艇A1選手（1号がA1でない場合） | +2 |
| 外艇ST速い（3〜6号どれかST≤0.12） | +2 |
| 複数外艇ST速い（3〜6号で≤0.13が2艇以上） | +3 |
| 外艇展示タイム最速（3〜6号） | +1 |

**C. 1号艇・2号艇の弱さ（最大9点・荒れる確率）**
| 条件 | 点数 |
|------|------|
| 1号艇スタート不安（ST≥0.18） | +3 |
| 1号艇モーター低調（2連率<0.30） | +2 |
| 1号艇B級 | +2 |
| 2号艇スタート不安（ST≥0.17） | +1 |
| 2号艇モーター低調（2連率<0.35） | +1 |

**D. 環境・条件（最大5点・荒れる確率）**
| 条件 | 点数 |
|------|------|
| 荒水面・強風会場（江戸川+2、戸田・平和島・鳴門・三国・下関+1） | +1〜2 |
| 強風≥5m | +1 |
| 波高≥15cm | +1 |
| 一般戦 | +1 |

**満点29点**。Aの配点は当初+6/+4/+2案だったが「市場条件だけで参戦ラインに届いてしまう」懸念から+4/+3/+1に減点し、B・Cの根拠なしにAだけで参戦しにくいよう調整済み。

> 過去の「PT13なんて見たことがない」という経験則から、満点に対する割合では参戦ラインを決められない。今回のPT_MIN_SCORE=13は相対的な厳しさからの推測値であり、実際のPT分布・配当データを見ながら調整する前提。

### 買い目選出方式（オッズ帯EV方式: strategy_version='4'）
軸選出スコア（コース位置点ベース）は廃止。4エージェント合成確率（ML40%+コース戦略25%+選手成績20%+モーター15%、
predict_race内のwin_probs）をそのまま各組み合わせの確率として使い、オッズ帯ごとにEV(確率×オッズ)が
高い順に選ぶだけのシンプルな方式に統一した。「脅威艇・軸スコア上位艇が絡む」等の追加フィルターは無し。

- **3連単（5点・オッズ帯方式）**:
  | 点数 | オッズ帯 | 選出方法 |
  |------|---------|---------|
  | 1点目 | 30〜99倍 | EV(確率×オッズ)最大の組み合わせ |
  | 2〜3点目 | 100〜199倍 | 同一帯からEV上位2点 |
  | 4点目 | 201〜300倍 | EV最大の組み合わせ |
  | 5点目 | 301倍以上（上限なし） | EV最大の組み合わせ |
  - 既に選出済みの組み合わせは除外（重複なし）
  - 該当オッズ帯に組み合わせが無い場合はその点をスキップ（フォールバックなし）
- **コスト**: 1レース最大500円
- **2連単は廃止**（2026-08-25）。3連単のみを予想・表示
- 神熱・見送りどちらのラベルでも同じ選出（見送りもデータ収集のため記録）

### （参考）旧・荒れPTスコアリング（src/model/predictor.py: _calc_arare_score）
現在の予想フローからは完全に切り離され、main.pyのバックテストモード専用として残っている
（get_recommendations内では未使用）。5カテゴリ合計最大30点（市場集中度はライブオッズ取得時のみ加算）：

**① 1号艇の弱さ（最大9点）**
| 条件 | 点数 |
|------|------|
| 1号艇展示ST遅い（≥0.18） | +3 |
| 1号艇モーター2連率低い（<0.30） | +3 |
| 1号艇B級（grade≤2） | +2 |
| 1号艇展示タイム最遅 | +1 |

**①' 2号艇の弱さ（最大4点）**
| 条件 | 点数 |
|------|------|
| 2号艇展示ST遅い（≥0.17） | +2 |
| 2号艇モーター2連率低い（<0.35） | +2 |

**② 外艇の脅威（最大10点）**
| 条件 | 点数 |
|------|------|
| 前付け（4〜6号が1〜2コース進入） | +3 |
| 外艇A1（1号がA1でない場合） | +2 |
| 外艇ST速い（≤0.12・最速1艇） | +2 |
| 複数外艇ST速い（≤0.13が2艇以上） | +2 |
| 外艇展示タイム最速（3〜6号） | +1 |

**③ 環境・条件（最大4点）**
| 条件 | 点数 |
|------|------|
| 風速≥7m | +1 |
| 波高≥15cm | +1 |
| 荒れ会場（江戸川+2、その他荒れ会場+1） | +1〜2 |
| 一般戦 | +1 |

**④ 市場集中度（最大3点・ライブオッズ取得時のみ）**
| 条件 | 点数 |
|------|------|
| 1号艇1着最安オッズ≤4倍（超人気集中） | +3 |
| 1号艇1着最安オッズ≤7倍（人気集中） | +2 |
| 1号艇1着最安オッズ≤12倍（やや人気） | +1 |

> 公衆が1号艇に集中しているほど外艇の配当が膨らむ。荒れPT（客観条件）と組み合わせることで「客観的にも崩れそうなのに公衆が気づいていないレース」を狙い撃てる。

## モデル構成（2026-08-25 見直し）
```
エージェント重み:
  ML（LightGBM）: 50%
  コース戦略:      22%
  選手成績:        18%
  モーター状態:    10%
```
- MLは57特徴量（コース・選手成績・モーター等含む）を学習データから直接フィットした唯一のデータ駆動コンポーネント。
  他3エージェントは同じ生データを人間が決めた固定係数で近似しているだけで学習・検証は経ていないため、
  MLの発言力を主軸に置き、他3エージェントは「MLが薄いデータで見誤りやすい場面を下支えする保険」という
  位置づけに変更（旧40/25/20/15→50/22/18/10）。この配分もバックテストで検証したものではなく判断による
  暫定値であり、下記のキャリブレーション検証データで妥当性を継続的に確認する前提。
- `src/agents/racer_performance.py`: 基準スコアを構成する8指標の重み合計が0.80しかなく1.0になっていない
  バグを修正（正規化して合計1.0に）。
- **モデル確率キャリブレーション検証**（`/stats`ページ）: 「モデルが確率X%と言った組み合わせが実際に
  何%当たっているか」を予測確率帯別に集計・可視化する機能を追加。予測確率と実際の的中率の乖離が
  小さければ4エージェント合成確率は信頼でき、大きければエージェント重み・温度スケーリング(T=2.5)の
  見直しが必要と判断できる。strategy_version='4'・PT_STATS_START_DATE以降のデータのみ対象。

## 注意事項
- Google Sheets APIは不要（sheets.pyはあるが `auto_runner.py` でオプション扱い）
- Sheetsを使う場合のみ `.env` に `SPREADSHEET_ID` と `GOOGLE_CREDENTIALS_PATH` が必要
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- Flask は `main.py --mode auto` 起動時に自動的にバックグラウンドスレッドで起動する
- データは `data/perry.db` に蓄積される
