# boatrace-predictor プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、Google Sheetsに自動記録する。

## 現在の予想設定

### 荒れ条件スコア
- `ARARE_MIN_SCORE = 7`（src/model/predictor.py）

### ラベル（勝負推奨）
| ラベル | 条件 | 色 |
|--------|------|----|
| **神熱** | 荒れPT≥7 かつ 追い風5m以上 | 金色 |
| **灼熱** | 荒れPT≥7 かつ 追い風なし | オレンジ |
| **熊熱** | 荒れPT=1 | 薄赤 |
| **見送り** | 上記以外 | グレー |

### 予想ティア（3種類）
| ティア | 点数 | PT条件 | 選出方法 |
|--------|------|--------|----------|
| 地熊目 | 2点 | 全PT通常記載・サマリー集計はPT1-3のみ | 全120通りからprob上位2点 |
| 熊フォメ | 可変 | 全PT通常記載・サマリー集計はPT1-3のみ | ML確率上位2艇×脅威艇フォーメーション |
| 展モタ | 6点 | 全PT通常記載 | 1着=1号固定、2着=pivot+外側、3着=2着+さらに外+複合次点 |

### 熊フォメの選出方法（ML＋脅威スコア型）
- **1着**: ML勝利確率上位2艇（kuma_first）
- **2着**: {1着2艇} ＋ 残りの中から脅威スコア最高艇（kuma_threat_a）= 3艇
- **3着**:
  - PT6以下 → 2着と同じ3艇（6点）
  - PT7以上 → 2着3艇 ＋ 脅威スコア次位艇（kuma_threat_b）= 4艇（12点）
- 脅威スコア（`_calc_threat_score`）の内訳:
  - 展示ST速い（0.10→+0.5、0.20→-0.5）
  - 今節平均ST速い（補強）
  - グレード高い（A1+0.6、A2+0.3）
  - アウトコース積極性（3〜6号艇のみ、選手スタイルデータ参照）

### 展モタの選出方法（パターンA・展示＋モーター複合型）
- **フォールバック順**: ①展示タイム2艇以上→②今節平均ST→③モーターのみ
- **複合スコア** = 展示（またはST）順位pt ＋ モーター2連対率順位pt（欠損は中央値補完）
- pivot = 複合スコア最高艇（2〜6号艇）
- 1着: {1号艇固定}
- 2着: {pivot, pivotの外側（outer1）} = 2艇
- 3着: {pivot, outer1, outer1のさらに外（outer2）, 複合スコア次点} = 最大4艇
- 形の例: pivot=3、outer1=4、outer2=5、次点=6 → `1-34-3456` = 6点

### 展モタの注意
- 展示タイムが2艇未満でも今節平均STかモーターで代替（見送りなし）

### 成績16シートの会場列
- 日付別シートと同様に▲/◎マーク付きで記録

### 荒れPTスコアリング（src/model/predictor.py: _calc_arare_score）
| 条件 | 点数 |
|------|------|
| 1号艇展示ST遅い（≥0.18） | +2 |
| 1号艇モーター2連率低い（<0.35） | +2 |
| 1号艇B級（grade≤2） | +2 |
| 外艇(4-6号)展示タイム最速 | +2 |
| 前付け（4-6号艇が1-2コース進入） | +2 |
| 1号艇展示タイム最遅 | +1 |
| 1号艇全国2連率低い（<0.40） | +1 |
| 外艇A1選手（1号艇がA1でない場合のみ） | +1 |
| 外艇ST速い（≤0.12、上限2点） | +1〜2 |
| 風速5m以上 | +1 |
| 追い風（wind_direction=tail） | +1追加 |
| 波高15cm以上 | +1 |
| 荒れ会場（江戸川+2、戸田/平和島/三国/鳴門/下関+1） | +1〜2 |
| 一般戦 | +1 |

※削除済み条件: 今節平均着順不振（全コース混在で不正確なため削除）

## Googleスプレッドシート構成
| シート | 用途 |
|--------|------|
| 日付別（例: 2026-06-11） | 当日の予想（自動追記） |
| 成績16 | レース結果と的中記録 |
| サマリー16 | PT別集計（会場別集計なし） |

### 日付別シートの列構成
A=日付, B=競艇場（▲/◎マーク付き）, C=レース, D=狙い, E=買い目（3連単）,
F=オッズ, G=イン逃げ率（逃げ推定XX%）, H=本日レース数,
I=勝負推奨, J=荒れPT（数字）, K=荒れ条件（理由テキスト）, L=1号艇状態

#### 会場マーク
- `▲` = 荒れやすい会場（江戸川・戸田・平和島・三国・鳴門・下関）
- `◎` = イン強・荒れにくい会場（大村・宮島・住之江・蒲郡・浜名湖・桐生）

#### イン逃げ率の色ハイライト（G列）
- 薄青: 50%未満（展モタ好機の目安）
- 無色: 50〜64%
- 薄赤: 65%以上（強逃げ・展モタ不利）

### サマリー15の構成
1. ティア別グループ比較（地熊目PT1-3合計・熊フォメPT1-3合計）
2. 地熊目セクション: PT1/PT2/PT3別に全期間合計＋日付別内訳
3. 熊フォメセクション: PT1/PT2/PT3別に全期間合計＋日付別内訳
4. 展モタセクション: PT1〜7以上別に全期間合計＋日付別内訳
5. モタフォメセクション: PT1〜7以上別に全期間合計＋日付別内訳
6. 会場別集計: 地熊目＋熊フォメ合算・展モタ単独・モタフォメ単独

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・ティア選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ |
| `src/output/sheets.py` | Google Sheets書き込み（RESULT_SHEET=成績15, SUMMARY_SHEET=サマリー15） |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは503/409エラーが出ることがある → リトライ処理済み（最大4回）
- 地熊目・熊フォメは全PTで成績16に記録、サマリー集計はPT1-3のみ
- 展モタは全PTで通常記録・集計
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- .envファイルにSPREADSHEET_IDとGOOGLE_CREDENTIALS_PATHが必要（Windowsローカルのみ）
- イン逃げ率は「会場ベース×レース番号×グレード×選手逃げ率×展示ST×2号艇差し圧力」の独自計算式
