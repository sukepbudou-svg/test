# boatrace-predictor プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、Google Sheetsに自動記録する。

- コード変更後に `git pull` を案内するときは、必ずその後に以下も伝えること：
  ```
  python main.py --mode auto

  を貼って予想を再スタートさせてください。

```

## Googleスプレッドシート構成
| シート | 用途 |
|--------|------|
| 日付別（例: 2026-08-06） | 当日の予想（自動追記） |
| 成績20 | レース結果と的中記録 |
| サマリー20 | PT帯別集計＋ラベル別集計 |

### 日付別シートの列構成
A=日付, B=競艇場（▲/◎マーク付き）, C=レース, D=狙い, E=買い目（3連単）,
F=オッズ, G=イン逃げ率（逃げ推定XX%）, H=本日レース数,
I=勝負推奨, J=荒れPT（数字）, K=荒れ条件（理由テキスト）, L=1号艇状態

#### 会場マーク
- `▲` = 荒れやすい会場（江戸川・戸田・平和島・三国・鳴門・下関）
- `◎` = イン強・荒れにくい会場（大村・宮島・住之江・蒲郡・浜名湖・桐生）

#### イン逃げ率の色ハイライト（G列）
- 薄青: 50%未満（展モタ好機の目安）
- 無色: 50〜64%
- 薄赤: 65%以上（強逃げ・展モタ不利）

### サマリー20の構成
1. PT帯別集計: PT1〜PT7以上別に大熊全ラベル合算（予想R数/的中数/的中率/間隔/総払戻/回収率/収支）
2. ラベル別集計: 大熊灼熱/熊熱/見送り別＋大熊全体
3. 大熊セクション: ラベル別に全期間合計＋日付別内訳

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・ティア選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ |
| `src/output/sheets.py` | Google Sheets書き込み（RESULT_SHEET=成績20, SUMMARY_SHEET=サマリー20） |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは503/409エラーが出ることがある → リトライ処理済み（最大4回）
- 大熊は全PTで成績20に記録・サマリー20に集計
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- .envファイルにSPREADSHEET_IDとGOOGLE_CREDENTIALS_PATHが必要（Windowsローカルのみ）
- イン逃げ率は「会場ベース×レース番号×グレード×選手逃げ率×展示ST×2号艇差し圧力」の独自計算式
