# boatrace-predictor プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、Google Sheetsに自動記録する。

## 現在の予想設定

### 荒れ条件スコア
- `ARARE_MIN_SCORE = 7`（src/model/predictor.py）

### ラベル（勝負推奨）
| ラベル | 条件 | 色 |
|--------|------|----|
| **神熱** | 荒れPT≥7 かつ 追い風5m以上 | 金色 |
| **灼熱** | 荒れPT≥7 かつ 追い風なし | オレンジ |
| **熊熱** | 荒れPT=1 | 薄赤 |
| **見送り** | 上記以外 | グレー |

### 予想ティア（4種類）
| ティア | 点数 | PT条件 | 選出方法 |
|--------|------|--------|----------|
| 小熊 | 4点 | 全PT | 1号艇+差し系外艇1艇が1着、ML+差しスコアで軸選出・形 `AB-C-DE` |
| 熊フォメ | 可変 | 全PT | ML確率上位2艇×脅威艇フォーメーション |
| 地熊2.0 | 6点固定 | 全PT | 1号艇1着固定・形 `1-AB-ABCD`（6点） |
| 大熊 | 4点 | 全PT | まくり系外艇TOP2が1着（差し外艇・1号艇除外）・形 `AB-C-DE` |

### 熊フォメの選出方法（ML＋脅威スコア型）
- **1着**: ML勝利確率上位2艇（kuma_first）
- **2着**: {1着2艇} ＋ 残りの中から脅威スコア最高艇（kuma_threat_a）= 3艇
- **3着**:
  - PT6以下 → 2着と同じ3艇（6点）
  - PT7以上 → 2着3艇 ＋ 脅威スコア次位艇（kuma_threat_b）= 4艇（12点）
- 脅威スコア（`_calc_threat_score`）の内訳:
  - 展示ST速い（0.10→+0.5、0.20→-0.5）
  - 今節平均ST速い（補強）
  - グレード高い（A1+0.6、A2+0.3）
  - アウトコース積極性（3〜6号艇のみ、選手スタイルデータ参照）

### 小熊の選出方法（差し展開型）
- **1着軸**: 1号艇 ＋ 差しスコア最高の外艇1艇（ML40%+差しポジション30%+ST20%+ET10%）
- **2着**: 残り艇のML条件付き確率×45%+ET×25%+ST×20%+ポジションボーナス×10% でスコア最高艇1艇
- **3着**: スコア次点2艇（合計4点）
- 色: 青緑背景＋白文字

### 大熊の選出方法（まくり展開型）
- **1着軸**: まくり候補艇TOP2（差し外艇・1号艇を除いた外艇からET45%+ML35%+ST20%+まくりボーナスで選出）
- **2着**: 残り艇のML条件付き確率スコア最高艇1艇
- **3着**: スコア次点2艇（合計4点）
- 色: 茶色背景＋白文字

### 地熊2.0の選出方法（1号艇1着固定・`1-AB-ABCD`形式）
- **形**: `1-AB-ABCD`（6点固定）
- **1着**: 1号艇固定（荒れないレースで1号艇が1着に来ることを前提）
- **スコア**: ML60% + ETランク30% + 内側ポジションボーナス10%（2号=0.02相当、微小）
- **2着A**: スコア1位の艇（1号艇除く）
- **2着B**: Aの直外側の艇（Aより大きい番号の最小艇）→ 外がなければスコア2位
- **3着C**: Bの直外側の艇 → 外がなければ次点
- **3着D**: スコア次点（A,B,C,1号以外）
- 3着が4艇未満の場合は残り艇から補完
- 例: `1-23-2345`、`1-34-3456`

### 成績19シートの会場列
- 日付別シートと同様に▲/◎マーク付きで記録

### 荒れPTスコアリング（src/model/predictor.py: _calc_arare_score）
| 条件 | 点数 |
|------|------|
| 1号艇展示ST遅い（≥0.18） | +2 |
| 1号艇モーター2連率低い（<0.35） | +2 |
| 1号艇B級（grade≤2） | +2 |
| 外艇(4-6号)展示タイム最速 | +2 |
| 前付け（4-6号艇が1-2コース進入） | +2 |
| 1号艇展示タイム最遅 | +1 |
| 1号艇全国2連率低い（<0.40） | +1 |
| 外艇A1選手（1号艇がA1でない場合のみ） | +1 |
| 外艇ST速い（≤0.12、上限2点） | +1〜2 |
| 風速5m以上 | +1 |
| 追い風（wind_direction=tail） | +1追加 |
| 波高15cm以上 | +1 |
| 荒れ会場（江戸川+2、戸田/平和島/三国/鳴門/下関+1） | +1〜2 |
| 一般戦 | +1 |

※削除済み条件: 今節平均着順不振（全コース混在で不正確なため削除）

## Googleスプレッドシート構成
| シート | 用途 |
|--------|------|
| 日付別（例: 2026-06-11） | 当日の予想（自動追記） |
| 成績19 | レース結果と的中記録 |
| サマリー19 | 全PT帯集計＋暴れ熊ラベル別集計 |

### 日付別シートの列構成
A=日付, B=競艇場（▲/◎マーク付き）, C=レース, D=狙い, E=買い目（3連単）,
F=オッズ, G=イン逃げ率（逃げ推定XX%）, H=本日レース数,
I=勝負推奨, J=荒れPT（数字）, K=荒れ条件（理由テキスト）, L=1号艇状態

#### 会場マーク
- `▲` = 荒れやすい会場（江戸川・戸田・平和島・三国・鳴門・下関）
- `◎` = イン強・荒れにくい会場（大村・宮島・住之江・蒲郡・浜名湖・桐生）

#### イン逃げ率の色ハイライト（G列）
- 薄青: 50%未満（展モタ好機の目安）
- 無色: 50〜64%
- 薄赤: 65%以上（強逃げ・展モタ不利）

### サマリー19の構成
1. 全PT帯集計: PT1〜PT7以上別に全ティア合算（予想R数/的中数/的中率/間隔/総払戻/回収率/収支）
2. 暴れ熊ラベル別集計: 暴れ熊(弱)/暴れ熊(中)/暴れ熊(強)別に全ティア合算
3. ティア別グループ比較: 小熊/大熊/神熊 × ラベル(弱/中/強)の組み合わせ
4. 小熊/大熊/神熊セクション: ラベル別に全期間合計＋日付別内訳

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・ティア選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ |
| `src/output/sheets.py` | Google Sheets書き込み（RESULT_SHEET=成績19, SUMMARY_SHEET=サマリー19） |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは503/409エラーが出ることがある → リトライ処理済み（最大4回）
- 小熊・大熊・熊フォメはすべて全PTで成績16に記録・サマリー集計
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- .envファイルにSPREADSHEET_IDとGOOGLE_CREDENTIALS_PATHが必要（Windowsローカルのみ）
- イン逃げ率は「会場ベース×レース番号×グレード×選手逃げ率×展示ST×2号艇差し圧力」の独自計算式
