# boatrace-predictor / PERRY AI プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、
ローカルWeb（Flask + SQLite）に自動記録する。
ツール名: **PERRY AI**（黒船のペリーをコンセプトにしたAI予想キャラクター）

## 現在の予想設定（2026-08-25 参戦ゲート方式）

### ラベル・参戦判定（src/model/predictor.py: _calc_entry_gate）
PTの単純加算方式を廃止し、「荒れる確率」と「配当の大きさ」を分けて判定する2ゲート方式に変更。

| ラベル | 条件 | 参戦 | 色 |
|--------|------|------|----|
| **神熱** | 客観条件 AND 市場条件 の両方成立 | ○ | ゴールド（#ffcc00）|
| **見送り** | いずれか不成立 | ✗ | グレー |

**客観条件**（荒れる確率＝①or②）:
| # | 条件 |
|---|------|
| ① | 1号艇のスタート不安（展示ST≥0.18） |
| ② | 荒水面・強風会場（戸田・平和島・鳴門・三国・下関・江戸川、または風速≥5m、または波高≥15cm） |

**市場条件**（配当の大きさ＝市場の見誤り）:
- 1号艇3連単ライブ最安オッズが **4〜10倍** の範囲内
- 4倍以下: 市場も1号艇を正しく評価している可能性が高く見送り（超人気集中）
- 10倍超: 市場が既にリスクを織り込み済みで旨みが薄いため見送り
- ライブオッズ未取得時は判定保留（見送り扱い、オッズ取得後に再評価）

> 客観条件だけでは「荒れやすさ」しか測れず、市場条件だけでは「本当に荒れるか」が分からない。両方が同時に成立する瞬間＝市場の見誤りを狙う。

### 買い目選出方式（コース+STスコア方式: strategy_version='3'）
- **軸選出スコア**: コース位置点 + 展示STボーナス + 選手等級ボーナス（合計スコア上位2艇が軸1・軸2）
  - コース位置: 1コース=6点, 2コース=5点, …, 6コース=1点（actual_courseで前付け反映）
    - 荒水面・強風会場（参戦ゲートの客観条件②に該当するレース。神熱/見送り問わず適用）は1〜2コースを-2点（内側優位性の減衰を反映）
  - STボーナス: ≤0.12:+4, 0.13〜0.14:+3, 0.15〜0.16:+2, 0.17:+1, ≥0.18:-2, データなし:0
  - 等級ボーナス: A1=+3, A2=+2, B1=+1, B2=0（grade_num: A1=4, A2=3, B1=2, B2=1）
  - モーター減点: 2連率<0.35 → -2点（弱モーター艇を軸から外す）
- **3連単（最大5点・オッズ帯方式）**:
  | 点数 | オッズ帯 | 選出方法 |
  |------|---------|---------|
  | 1点目 | 軸1-軸2（制限なし） | 3着候補: ①脅威艇（A1選手/前付け/ST速） → ②ST速い外艇(3〜6号でST≤0.14) → ③ETワースト順 |
  | 2点目 | 100〜160倍 | 脅威艇・軸スコア上位3艇が絡む組み合わせに絞り、EV(確率×オッズ)最大を選出 |
  | 3点目 | 161〜230倍 | 同上 |
  | 4点目 | 231〜300倍 | 同上 |
  | 5点目 | 301倍以上（上限なし） | 同上 |
  - 2〜5点目は「脅威艇 or 軸スコア上位3艇（軸1・軸2・スコア3位）が絡む組み合わせ」に絞ってからEV最大を選ぶ。該当なしの場合は帯全体でEV最大にフォールバック
  - 既に選出済みの組み合わせは除外（重複なし）
- **コスト**: 1レース最大500円
- **2連単は廃止**（2026-08-25）。3連単のみを予想・表示
- 神熱・見送りどちらのラベルでも同じ選出（見送りもデータ収集のため記録）

### （参考）旧・荒れPTスコアリング（src/model/predictor.py: _calc_arare_score）
参戦判定には使用しなくなったが、脅威艇（3着候補選出）の検出に内部で使用し続けている。
5カテゴリ合計最大30点（市場集中度はライブオッズ取得時のみ加算）：

**① 1号艇の弱さ（最大9点）**
| 条件 | 点数 |
|------|------|
| 1号艇展示ST遅い（≥0.18） | +3 |
| 1号艇モーター2連率低い（<0.30） | +3 |
| 1号艇B級（grade≤2） | +2 |
| 1号艇展示タイム最遅 | +1 |

**①' 2号艇の弱さ（最大4点）**
| 条件 | 点数 |
|------|------|
| 2号艇展示ST遅い（≥0.17） | +2 |
| 2号艇モーター2連率低い（<0.35） | +2 |

**② 外艇の脅威（最大10点）**
| 条件 | 点数 |
|------|------|
| 前付け（4〜6号が1〜2コース進入） | +3 |
| 外艇A1（1号がA1でない場合） | +2 |
| 外艇ST速い（≤0.12・最速1艇） | +2 |
| 複数外艇ST速い（≤0.13が2艇以上） | +2 |
| 外艇展示タイム最速（3〜6号） | +1 |

**③ 環境・条件（最大4点）**
| 条件 | 点数 |
|------|------|
| 風速≥7m | +1 |
| 波高≥15cm | +1 |
| 荒れ会場（江戸川+2、その他荒れ会場+1） | +1〜2 |
| 一般戦 | +1 |

**④ 市場集中度（最大3点・ライブオッズ取得時のみ）**
| 条件 | 点数 |
|------|------|
| 1号艇1着最安オッズ≤4倍（超人気集中） | +3 |
| 1号艇1着最安オッズ≤7倍（人気集中） | +2 |
| 1号艇1着最安オッズ≤12倍（やや人気） | +1 |

> 公衆が1号艇に集中しているほど外艇の配当が膨らむ。荒れPT（客観条件）と組み合わせることで「客観的にも崩れそうなのに公衆が気づいていないレース」を狙い撃てる。

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・買い目選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ・DB書き込み |

| `web/database.py` | SQLite操作 |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは不要（sheets.pyはあるが `auto_runner.py` でオプション扱い）
- Sheetsを使う場合のみ `.env` に `SPREADSHEET_ID` と `GOOGLE_CREDENTIALS_PATH` が必要
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- Flask は `main.py --mode auto` 起動時に自動的にバックグラウンドスレッドで起動する
- データは `data/perry.db` に蓄積される
