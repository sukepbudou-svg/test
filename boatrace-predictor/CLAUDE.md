# boatrace-predictor / PERRY AI プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、
ローカルWeb（Flask + SQLite）に自動記録する。
ツール名: **PERRY AI**（黒船のペリーをコンセプトにしたAI予想キャラクター）

## 現在の予想設定（2026-08-15 心機一転）

### ラベル（荒れPT基準）
| ラベル | 条件 | 参戦 | 色 |
|--------|------|------|----|
| **プチュン** | 荒れPT≥8 | ○ | 赤（#d93232）|
| **黒船熱** | 荒れPT=7 | ○ | オレンジ（#d97c28）|
| **見送り** | 荒れPT≤6 | ✗ | グレー |

- 参戦ライン: **7P以上**
- 見送りでも予想を出力（データ収集のため）
- 出力は現在3点（主役艇固定 × EV上位3点）← フィルター通過後が2通りの場合は2点になる

### 買い目選出方式（hero1着固定 × 期待値上位3点 + 最低倍率フィルター） ← 点数変更時はここも更新すること
1. **主役艇（hero）選出**: 2〜6号艇から複合スコア最高の1艇
   - ST速さ (40%) + ET速さ (30%) + グレード (20%) + まくり実績 (10%)
   - 外枠ペナルティ: 4号艇-0.05 / 5号艇-0.10 / 6号艇-0.18（2・3号艇はペナルティなし）
   - 2号艇は1号艇が弱い荒れレースで有利なためペナルティなし
2. **2着・3着はレース動態スコアリングで決定**:
   - 120通りの組み合わせから「hero が1着」の組み合わせだけ抽出
   - ラベル別最低倍率フィルターを適用
     - プチュン（荒れPT≥8）: **40倍以上**の組み合わせのみ
     - 黒船熱（荒れPT=7）: **20倍以上**の組み合わせのみ
     - 見送り: フィルターなし（データ収集用）
   - フィルター通過後、**動態スコア上位3点**を採用

   **動態スコア（合計100%）:**
   | 指標 | 2着重み | 3着重み | 根拠 |
   |------|---------|---------|------|
   | STタイミングの近さ | 28% | 12% | 第1ターンで隣り合う艇が2着になりやすい |
   | ET展示タイム順位 | 23% | 12% | 純粋なボート速度 |
   | コース位置ロジック | 17% | 8% | まくり型→内艇生存 / 差し型→隣接艇継続 |

> **重要**: EV（期待値）順ではなく実際の競艇動態に基づく選出に変更。
> 汎用MLモデルではなく荒れレース特有の動態パターンを優先。

### 荒れPTスコアリング（src/model/predictor.py: _calc_arare_score）
5カテゴリ合計最大30点（市場集中度はライブオッズ取得時のみ加算）：

**① 1号艇の弱さ（最大9点）**
| 条件 | 点数 |
|------|------|
| 1号艇展示ST遅い（≥0.18） | +3 |
| 1号艇モーター2連率低い（<0.30） | +3 |
| 1号艇B級（grade≤2） | +2 |
| 1号艇展示タイム最遅 | +1 |

**①' 2号艇の弱さ（最大4点）**
| 条件 | 点数 |
|------|------|
| 2号艇展示ST遅い（≥0.17） | +2 |
| 2号艇モーター2連率低い（<0.35） | +2 |

**② 外艇の脅威（最大10点）**
| 条件 | 点数 |
|------|------|
| 前付け（4〜6号が1〜2コース進入） | +3 |
| 外艇A1（1号がA1でない場合） | +2 |
| 外艇ST速い（≤0.12・最速1艇） | +2 |
| 複数外艇ST速い（≤0.13が2艇以上） | +2 |
| 外艇展示タイム最速（3〜6号） | +1 |

**③ 環境・条件（最大4点）**
| 条件 | 点数 |
|------|------|
| 風速≥7m | +1 |
| 波高≥15cm | +1 |
| 荒れ会場（江戸川+2、その他荒れ会場+1） | +1〜2 |
| 一般戦 | +1 |

**④ 市場集中度（最大3点・ライブオッズ取得時のみ）**
| 条件 | 点数 |
|------|------|
| 1号艇1着最安オッズ≤4倍（超人気集中） | +3 |
| 1号艇1着最安オッズ≤7倍（人気集中） | +2 |
| 1号艇1着最安オッズ≤12倍（やや人気） | +1 |

> 公衆が1号艇に集中しているほど外艇の配当が膨らむ。荒れPT（客観条件）と組み合わせることで「客観的にも崩れそうなのに公衆が気づいていないレース」を狙い撃てる。

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・買い目選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ・DB書き込み |
| `web/app.py` | Flask Webアプリ |
| `web/database.py` | SQLite操作 |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは不要（sheets.pyはあるが `auto_runner.py` でオプション扱い）
- Sheetsを使う場合のみ `.env` に `SPREADSHEET_ID` と `GOOGLE_CREDENTIALS_PATH` が必要
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- Flask は `main.py --mode auto` 起動時に自動的にバックグラウンドスレッドで起動する
- データは `data/perry.db` に蓄積される
