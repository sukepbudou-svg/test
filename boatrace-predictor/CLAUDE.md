# boatrace-predictor / PERRY AI プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、
ローカルWeb（Flask + SQLite）に自動記録する。
ツール名: **PERRY AI**（黒船のペリーをコンセプトにしたAI予想キャラクター）

## 現在の予想設定（2026-08-20 神熱シグナル方式）

### ラベル
| ラベル | 条件 | 参戦 | 色 |
|--------|------|------|----|
| **神熱** | シグナル≥2 かつ 超人気集中でない | ○ | ゴールド（#ffcc00）|
| **見送り** | シグナル≤1 または 超人気集中 | ✗ | グレー |

### 神熱シグナル（6条件）
| # | 条件 | arare_reasons キーワード |
|---|------|------------------------|
| ① | 1号艇または2号艇モーター2連率低い | `M低` |
| ② | 展示タイム最遅艇あり | `展示最遅` |
| ③ | 外艇（4〜6号）にA1選手 | `A1選手` |
| ④ | 荒れ会場（戸田・平和島・鳴門・三国・下関・江戸川） | `荒れ会場` / `江戸川` |
| ⑤ | 前付けあり（外艇が1〜2コース進入） | `前付け` |
| ⑥ | 1号艇展示ST遅い（≥0.18） | `1号ST遅` |

**除外条件**: 1号艇ライブ最安≤4倍（超人気集中）→ データ分析で神熱出現率0.41xと逆効果

### 買い目選出方式（ETベース: 2連単2点＋3連単2点）
- **1着軸**: 展示タイム速い順1位(ET1)・2位(ET2)
- **2連単2点**: ET1-ET2 と ET2-ET1（両方向）
  - 例: ET1=3号艇、ET2=1号艇 → 3-1 と 1-3 を購入
- **3連単2点**: ET1-ET2-3着 と ET2-ET1-3着（70〜250倍・範囲外なら次点3着候補へ）
  - 3着候補: 脅威艇（A1選手/前付け/ST速のある艇）優先 → ETワースト順
  - 脅威艇2艇以上なら3点目追加
- コスト: 1レース最大400円（2連単100円×2 ＋ 3連単100円×2）
- 6号艇1着のみ除外（1コース最遠のため）
- 神熱・見送りどちらのラベルでも同じ選出（見送りもデータ収集のため記録）
- 的中判定: 2連単は実結果の1-2着と一致で的中

### 荒れPTスコアリング（src/model/predictor.py: _calc_arare_score）
5カテゴリ合計最大30点（市場集中度はライブオッズ取得時のみ加算）：

**① 1号艇の弱さ（最大9点）**
| 条件 | 点数 |
|------|------|
| 1号艇展示ST遅い（≥0.18） | +3 |
| 1号艇モーター2連率低い（<0.30） | +3 |
| 1号艇B級（grade≤2） | +2 |
| 1号艇展示タイム最遅 | +1 |

**①' 2号艇の弱さ（最大4点）**
| 条件 | 点数 |
|------|------|
| 2号艇展示ST遅い（≥0.17） | +2 |
| 2号艇モーター2連率低い（<0.35） | +2 |

**② 外艇の脅威（最大10点）**
| 条件 | 点数 |
|------|------|
| 前付け（4〜6号が1〜2コース進入） | +3 |
| 外艇A1（1号がA1でない場合） | +2 |
| 外艇ST速い（≤0.12・最速1艇） | +2 |
| 複数外艇ST速い（≤0.13が2艇以上） | +2 |
| 外艇展示タイム最速（3〜6号） | +1 |

**③ 環境・条件（最大4点）**
| 条件 | 点数 |
|------|------|
| 風速≥7m | +1 |
| 波高≥15cm | +1 |
| 荒れ会場（江戸川+2、その他荒れ会場+1） | +1〜2 |
| 一般戦 | +1 |

**④ 市場集中度（最大3点・ライブオッズ取得時のみ）**
| 条件 | 点数 |
|------|------|
| 1号艇1着最安オッズ≤4倍（超人気集中） | +3 |
| 1号艇1着最安オッズ≤7倍（人気集中） | +2 |
| 1号艇1着最安オッズ≤12倍（やや人気） | +1 |

> 公衆が1号艇に集中しているほど外艇の配当が膨らむ。荒れPT（客観条件）と組み合わせることで「客観的にも崩れそうなのに公衆が気づいていないレース」を狙い撃てる。

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・買い目選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ・DB書き込み |
| `web/app.py` | Flask Webアプリ |
| `web/database.py` | SQLite操作 |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは不要（sheets.pyはあるが `auto_runner.py` でオプション扱い）
- Sheetsを使う場合のみ `.env` に `SPREADSHEET_ID` と `GOOGLE_CREDENTIALS_PATH` が必要
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- Flask は `main.py --mode auto` 起動時に自動的にバックグラウンドスレッドで起動する
- データは `data/perry.db` に蓄積される
