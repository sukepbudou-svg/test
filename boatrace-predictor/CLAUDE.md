# boatrace-predictor プロジェクト概要

## 概要
競艇3連単予想ツール。LightGBMモデル＋複数エージェントで予想を生成し、Google Sheetsに自動記録する。

## 開発ブランチ
`claude/update-april-7-summary-ceGQV`

## 実行コマンド（Windows）
```
# 最新コードを取得
git pull

# 自動予想モード（発走10分前に予想・8分後に結果記録）
python main.py --mode auto

# その他
python main.py --mode predict    # 一括予想（デバッグ用）
python main.py --mode backtest   # バックテスト
python main.py --mode train      # モデル再学習
```

## 現在の予想設定

### 荒れ条件スコア
- `ARARE_MIN_SCORE = 7`（src/model/predictor.py）
- スコア7以上のレースのみ「神熱」として予想を出力
- スコア未満は「見送り」として記録（予想・成績ともに記入する）

### 予想ティア（4種類）
| ティア | 点数 | 選出方法 |
|--------|------|----------|
| 地熊目 | 2点 | 全PT対象・全120通りからprob上位2点 |
| 新本命穴 | 1点 | PT4以上・展示/ST/グレードから脅威艇特定→脅威艇-1号艇-残り |
| 新超穴 | 1点 | PT4以上・脅威艇-1号艇除外の2番手-残り |
| フォーメーション | 6〜8点 | PT5以上・1着:確率上位2艇、2着:確率上位2艇+脅威艇A、3着:2着3艇+脅威艇B |

### ラベル
- **神熱**（金色）: 荒れ条件スコア≥7のレース
- **見送り**: 荒れ条件スコア<7のレース（予想は出すが賭けない）

## Googleスプレッドシート構成
| シート | 用途 |
|--------|------|
| 日付別（例: 2026-05-10） | 当日の予想（自動追記） |
| 成績12 | レース結果と的中記録 |
| サマリー12 | 神熱・見送りの集計＋ティア別グループ比較（全期間＋日付別） |

### 日付別シートの列構成
A=日付, B=競艇場, C=レース, D=狙い, E=買い目, F=的中確率,
G=オッズ, H=期待回収率, I=信頼度, J=1号逃げ率（逃げ推定XX%）, K=本日レース数,
L=勝負推奨, M=荒れPT（数字）, N=荒れ条件（理由テキスト）

### 成績10の列構成
A=日付, B=競艇場, C=レース, D=狙い, E=予想買い目, F=的中確率,
G=期待回収率, H=実際の結果, I=実際の払戻, J=的中, K=収支,
L=本日レース数, M=信頼度, N=勝負推奨, O=荒れPT（数字）

## モデル構成
```
エージェント重み:
  ML（LightGBM）: 40%
  コース戦略:      25%
  選手成績:        20%
  モーター状態:    15%
```

## バックテスト結果（参考）
- スコア7: 神熱ROI 124.0%、荒れ条件優位性1.52倍、対象1135レース
- スコア6: 神熱ROI 109.8%、荒れ条件優位性1.44倍、対象1927レース
- → スコア7を採用中

## 主要ファイル
| ファイル | 役割 |
|----------|------|
| `src/model/predictor.py` | 予想エンジン・荒れ条件スコアリング・ティア選出 |
| `src/scheduler/auto_runner.py` | 発走時刻管理・自動ループ |
| `src/output/sheets.py` | Google Sheets書き込み（RESULT_SHEET=成績10, SUMMARY_SHEET=サマリー10） |
| `src/agents/racer_performance.py` | 選手成績エージェント |
| `src/agents/course_strategy.py` | コース戦略エージェント |
| `src/agents/motor_form.py` | モーター状態エージェント |

## 注意事項
- Google Sheets APIは503/409エラーが出ることがある → リトライ処理済み（最大4回）
- 見送りレースも予想・成績ともに記入する仕様
- `--mode predict` は一括取得のため展示データが取れないことがある → 本番は `--mode auto` を使う
- .envファイルにSPREADSHEET_IDとGOOGLE_CREDENTIALS_PATHが必要（Windowsローカルのみ）
