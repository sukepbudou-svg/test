# ボートレース予想Webツール

Flask + HTML によるローカル動作のボートレース3連単予想ツールです。

## セットアップ

```bash
cd boatrace-web
pip install -r requirements.txt
python app.py
```

ブラウザで http://localhost:5001 を開いてください。

## 機能

- 日付・開催場・レース・風の条件入力
- 6艇それぞれのコース・展示タイム・周回・周り足・チルト・平均ST・体重の入力
- 平均ST・展示タイムデータの自動貼り付け解析
- コース展開パターンに基づく3連単予想（本命・対抗・穴）
  - 1コース逃げ
  - 4コースまくり / まくり差し（4-1系）
  - 5コースまくり差し → 2着は1号艇
  - 6コースまくり差し → 2着は1号艇
- ダークテーマUI
